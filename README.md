# step_motor_ABtestbed

A, B 두 시험대의 스텝모터 구동 펌웨어이다. 두 소스는 시험대에 적재하여 운용 중인 판본과 동일하다.

## 1. 구성

| 항목 | A (서비서) | B (클라이언트) |
|---|---|---|
| 제어기 | WeAct Black Pill V3.x (STM32F411CEU6) | Arduino Uno R3 |
| 구동부 | 볼스크류 직선 이송 | 커플러 회전 |
| 드라이버 / 모터 | SBD-20 / NK266 | SBD-20 / NK-266 |
| 명령 단위 | mm | 회전수 |
| 위치 계측 | 홀센서 A3144E, 자석 2개 | 없음 |
| 호스트 연결 | USB CDC 115200 | USB 시리얼 115200 |
| 소스 | `A_servicer_blackpill_f411/src/main.cpp` | `B_client_arduino_uno/client_dock.ino` |

두 펌웨어 모두 스텝 펄스를 비차단 방식으로 생성한다. `loop()`에서 반주기마다 STEP 핀을 반전시키며 `delay()`로 정지하지 않는다. 따라서 이송 중에도 시리얼 명령을 수신한다.

## 2. 신호 극성

SBD-20은 COM 단자의 결선에 따라 입력 신호의 유효 극성이 반전된다. A와 B는 결선이 서로 다르므로, 한쪽 코드를 다른 쪽으로 이식할 때는 극성부터 확인한다.

| 항목 | A (서비서) | B (클라이언트) |
|---|---|---|
| COM 결선 | GND (com.cathode) | 5 V (com.anode) |
| STEP | 대기 LOW, HIGH가 펄스 | 대기 HIGH, LOW가 펄스 |
| EN | LOW에서 활성 | HIGH에서 활성 (`ENPOL=1`) |
| GPIO 구성 | push-pull | push-pull |

A의 EN 극성은 벤치 시험으로 확정하였다. 데이터시트 서술(포토커플러 도통이 비활성에 대응)과 반대로 읽히므로 유의한다.

## 3. A: 서비서 (STM32F411CEU6)

### 3.1 핀 배치

| 기능 | 핀 |
|---|---|
| STEP | PB6 |
| DIR | PB7 |
| EN | PB8 |
| 홀센서 출력 | PB10 (5 V 허용, 하강 엣지 인터럽트) |
| 릴레이 8채널 (밸브) | PB12, PB13, PB14, PB15, PA8, PA9, PA10, PB5 |
| 상태 LED | PC13 (active-low) |

### 3.2 구동

`motor_move(mm)`는 이송량을 스텝 수로 환산하고 방향과 여자를 설정한 뒤 즉시 복귀한다. 실제 펄스는 `motor_update()`가 `loop()` 주기마다 생성하며, 반주기 경과 시 STEP을 반전하고 하강 엣지에서 스텝을 계수한다.

가감속은 `mot_delay_at(i)`가 스텝 위치에 대한 반주기를 산출한다. 기본은 선형 보간이고, `accel_profile = 1`이면 지수 보간을 적용한다. 출발 주기 1100 µs에서 최고속 150 µs까지 1000스텝에 걸쳐 변화시킨다. 출발 주기는 정지 마찰 돌파를 위한 값이다.

환산계수는 `steps_per_mm = 400`이다(800분주, 리드 2 mm). 행정은 `stroke_mm = 65`이다.

여자 유지 정책 `hold`는 세 값을 갖는다. 0은 이동 후 해제, 1은 상시 유지, 2는 닫힘 방향 이동 뒤에만 유지한다. 운용값은 2이다. 결합 상태에서 축이 역구동되지 않아야 하는 반면, 열림 이동과 교정 이동 뒤에는 여자를 해제하여 발열을 억제한다.

### 3.3 홀센서 계측과 탈조 판정

회전축 원주면에 자석 두 개를 180도 간격으로 부착하여 1회전당 2펄스를 얻는다. 벤치 시험에서 `hall_per_mm = 2.0`을 확정하였다(60 mm 왕복 시 119~120펄스).

인터럽트 처리부는 펄스 간격을 근거로 잡음 엣지를 배제한다. 판별 기준을 하나의 상수로 두면 성립하지 않는다. 유효 펄스의 간격 자체가 가속 초기 약 440 ms에서 최고속 약 60 ms까지 변하기 때문이다. `hall_min_interval()`은 현재 스텝 주기로부터 축이 물리적으로 낼 수 있는 최소 간격을 산출하고, 그보다 짧은 간격으로 도달한 엣지를 배제한다. 배제 수는 `hall_rejected`에 누적한다. 여유 계수 `hall_dyn_marg`는 0.5가 적정하다. 0.75로 좁히면 유효 펄스까지 배제된다.

탈조 가드 `stall_en`은 명령 이동량과 홀 계측값의 차가 `stall_mm`를 초과하면 이송을 중단한다. 초기값은 비활성이다. 자석 부착과 환산계수 검증을 마친 뒤에 활성화한다. 홀센서가 응답하지 않는 상태에서 활성화하면 정상 이송을 탈조로 오판한다.

홀센서는 단일 채널이므로 회전 방향을 구분하지 못한다. 이동량의 크기만 계측되며 초과 이송은 검출되지 않는다.

### 3.4 명령

ASCII 한 행 단위이며 개행으로 종료한다.

```
MOVE <mm>                         이송 (+정방향 / -역방향)
STOP                              즉시 정지
GRIP OPEN|CLOSE|STOP|FREE|<mm>    행정 단위 별칭 (FREE는 이송 없이 여자만 해제)
PARAMS / GETP [name] / SETP <name> <val>   파라미터 조회 및 설정
HALL / HALLRST / HALLMON <0|1>    홀센서 조회, 계수 초기화, 엣지 출력
STAT / HELP / BOOT                상태, 도움말, ROM DFU 재진입
RLY <1-8> <0|1> / RLYALL <0-255>  릴레이(밸브)
```

파라미터 15개는 `PARAM_REG[]`에 등록하며, `SETP`로 재적재 없이 변경한다. 값은 RAM에 있으므로 재부팅하면 초기값으로 복귀한다.

### 3.5 빌드 및 적재

```bash
pio run -d A_servicer_blackpill_f411                 # 빌드
pio run -d A_servicer_blackpill_f411 -t upload       # ROM DFU 적재
```

최초 적재만 BOOT0과 RESET으로 ROM DFU에 진입한다. 이후에는 시리얼로 `BOOT`를 전송하면 펌웨어가 부트로더로 분기하므로 버튼 조작 없이 재적재한다.

`reboot_to_bootloader()`는 수정하지 않는다. 클럭과 USB 초기화 순서가 검증된 절차이다.

## 4. B: 클라이언트 (Arduino Uno R3)

### 4.1 핀 배치

| 기능 | 핀 |
|---|---|
| DIR | D7 |
| STEP | D6 |
| EN | D5 |
| COM | 5 V |
| 릴레이 (밸브 1, 2, 3, 7) | D2, D3, D4, D10 |
| 압력센서 2채널 (DPH-100, 1~5 V) | A0, A1 |
| 상태 LED | D13 (구동 중 점등) |

배선은 [`B_client_arduino_uno/WIRING.md`](B_client_arduino_uno/WIRING.md)에 정리하였다. 공통 접지, 릴레이 코일 전원 분리, 압력센서 4선 색상 구분을 포함한다.

### 4.2 구동

`startMove(revs)`는 여자와 방향을 설정하고 잔여 스텝 수만 적재한 뒤 복귀한다. `serviceStepper()`는 `loop()`과 시리얼 수신 루프 양쪽에서 호출한다. 긴 명령을 처리하는 동안에도 펄스열이 끊기지 않도록 하기 위함이다.

기본값은 반주기 400 µs, 1600 step/rev이며, 프리셋 이동량 `MOVEREV`는 2.0회전이다.

`HOLD`는 기본 활성이다. 커플러가 하중 경로에 있어 여자를 해제하면 스크류가 역구동되는 현상을 시험대에서 확인하였다. 장기 보관 시에만 해제한다.

`AUTORET`은 ENGAGE 시 복귀 이동을 자동으로 예약한다. 대기 시간은 명령 시점이 아니라 이동 완료 시점부터 계수한다. 이동 시간이 길기 때문이다(9회전 기준 약 11초). 명령 시점부터 계수하면 짧은 대기값이 이동 도중에 만료되어 유지 시간이 남지 않는다.

`SCHED`는 지정 시간 뒤에 한 번 동작하는 예약 이동이다. 명령 계통이 포고핀을 경유하므로 분리 후에는 이 보드에 명령을 전달할 수 없다. 결합 상태에서 예약을 설정하면 분리 뒤 커플러가 자동으로 복귀한다.

### 4.3 명령

```
STEP <revs>                       회전 이송 (+CW / -CCW)
ENGAGE / RELEASE                  ±MOVEREV 프리셋 이동
SCHED ENGAGE|RELEASE <sec> / SCHED OFF     예약 이동
STEPSTOP                          정지 및 여자 해제, 예약 취소
GETP / SETP <name> <val>          SPEED, SPR, DIRINV, ENPOL, MOVEREV, AUTORET, HOLD
VER / STAT / PRES                 버전, 상태, 압력 판독
RLY <1-8> <0|1> / RLYALL <0-255>  릴레이(밸브)
```

응답은 `OK` 또는 `ERR`로 시작하는 한 행이다.

### 4.4 빌드 및 적재

Uno는 DFU를 지원하지 않으므로 hex를 생성하여 avrdude로 적재한다.

```bash
pio run -d B_client_arduino_uno                      # .pio/build/uno/firmware.hex 생성
avrdude -c arduino -p atmega328p -P <포트> -b 115200 -U flash:w:firmware.hex:i
```

Uno는 시리얼 개방 시 DTR 신호로 재시작한다. 포트를 연 뒤 2초가량 대기하고 명령을 전송한다.

## 5. 유의사항

두 소스는 운용본 그대로이므로 스텝모터 구동 외에 릴레이와 압력센서 처리가 함께 들어 있다. 구동부만 확인하려면 A는 `motor_*`와 `hall_*` 함수를, B는 `serviceStepper`, `startMove`, `serviceSchedule`을 참조한다.

A의 `STAT` 출력 형식은 상위 소프트웨어와의 인터페이스 규약이다. `bulldozer:` 행 앞에 새 행을 삽입하지 않으며, 그 뒤 어느 행에도 `IDLE` 문자열을 두지 않는다. 근거는 소스 주석에 있다.

A에 펄스 폭 검사를 도입하였다가 철회하였다. 유효 펄스를 잡음으로 오판하여 이동량 계측이 악화되었다. 실파형을 계측하기 전에는 재도입하지 않는다.
