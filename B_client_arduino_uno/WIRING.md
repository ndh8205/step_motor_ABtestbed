# Client Docking-Port Arduino (Uno R3) — 배선 가이드

`client_dock.ino` 기준. **실물 배선 확정 2026-07-20** (사용자 배선도 + SBD-20 데이터시트).
아두이노 우노가 클라이언트 도킹포트의 밸브 릴레이 4(1·2·3·7), 커플러 스텝모터(SBD-20+NK-266),
압력센서 2(DPH-100)를 구동/측정. jetson1 USB(/dev/gaimsat_client)로 제어.

> 참고: 기록(util/refuel_dock/, 메모리)은 클라이언트 스텝을 **SCD-10+NK-245**로 적어놨지만,
> 실물은 **서비서 계열 SBD-20+NK-266**을 쓴다. 실물 배선이 정답.

## 1. 우노 핀 배치
| 기능 | 우노 핀 | 연결 대상 | 비고 |
|------|---------|-----------|------|
| 릴레이 1 | **D2** | 릴레이보드 IN1 | 클라이언트 밸브1 |
| 릴레이 2 | **D3** | IN2 | 밸브2 |
| 릴레이 3 | **D4** | IN3 | 밸브3 |
| 릴레이 7 | **D10** | IN7 | 밸브7 |
| 커플러 DIR | **D7** | SBD-20 **DIR** | 방향 (실물 CW 확인) |
| 커플러 STEP | **D6** | SBD-20 **STP** | 1600 step/rev, ~400µs 펄스 |
| 커플러 EN | **D5** | SBD-20 **EN** | 이동 중만 활성 |
| 커플러 COM | **5V** | SBD-20 **COM** | com.anode (COM=5V) |
| 압력센서 1 | **A0** | DPH-100 #1 아날로그 out | 1~5V |
| 압력센서 2 | **A1** | DPH-100 #2 아날로그 out | 1~5V |
| 상태 LED | D13 | (온보드) | 스텝 구동 중 점등 |
| 전원 | USB (jetson1) | — | 우노 5V/500mA |

> 서비서 밸브 4·5·6은 **서비서 블랙필**이 구동(아두이노 아님). 그래서 그 핀 자리(구 D5·D6·D7)를 스텝에 재사용.
> 여유핀: D8·D9·D11·D12.

## 2. 릴레이 보드 (클라이언트 밸브 4채널, active-LOW)
IN 핀 LOW = 릴레이 ON(밸브 open), 부팅 시 HIGH=OFF.
- `IN1·IN2·IN3·IN7` → 우노 `D2·D3·D4·D10`
- 릴레이 VCC(로직) → 우노 `5V`, GND → 우노 `GND`
- 🚨 JD-VCC(코일측) → **별도 5V 전원** + VCC–JD-VCC 점퍼 제거. 우노 5V로 코일 돌리지 말 것.

## 3. 커플러 스텝모터 (SBD-20 드라이버 + NK-266 모터)
사용자 배선도 확정. **COM=5V = 데이터시트 com.anode(NPN) 구성 → 신호 active-LOW.**

**아두이노 → SBD-20 (신호선 3 + COM):**
- 우노 `D7` → SBD-20 **DIR**
- 우노 `D6` → SBD-20 **STP**
- 우노 `D5` → SBD-20 **EN**
- 우노 `5V` → SBD-20 **COM** (공통 양극)
- 우노 `GND` ↔ SBD-20 GND (공통 접지)
- M4 스위치 = **ON**(3.3~5V 신호, 270Ω*3). 우노 5V 로직 정합.

**SBD-20 → 모터/전원:**
- **A+ / A- / B+ / B-** ← NK-266 모터 4선(코일 A/B)
- **V+ / GND** ← **24V 배터리**(별도 전원, 우노와 별개). V+←24V+, GND←24V−.

**극성 (com.anode 기준, 펌웨어):**
- EN: `EN_ENABLE=HIGH` (COM=5V서 HIGH=옵토 OFF=enable, "옵토 ON=disable"). 이동 시 활성, idle 해제.
- STEP: idle HIGH(옵토 OFF), 펄스 LOW. DIR: HIGH/LOW = 방향(실물 CW 확인).
- ⚠️ EN 활성 극성·DIR 방향은 **실물 테스트로 확정**(안 돌면 EN_ENABLE 뒤집기, 방향 반대면 DIR 반전).

## 4. 압력센서 2 (DPH-100 헤드 **독립사용**, 4선, 1~5V)
데이터시트 확인(`data/data_ICD/dph-100_dpc-100_e_cata.pdf` p.12 "independent use of sensor head").
6선(갈/파/회/검/흰/분)은 **DPC-100 컨트롤러** 케이블이고, 실물은 헤드 직결 **4선**(갈/파/검/흰).

| 선 색 | 기능 | 연결 |
|------|------|------|
| 갈색 Brown | +V (12~24V) | 별도 24V **(+)** — 스텝 24V 공유 가능 |
| 파랑 Blue | 0V | 24V **(−)** + **우노 GND** (공통접지 필수, 두 군데) |
| 검정 Black | 아날로그 **1~5V** | 우노 `A0`(#1) / `A1`(#2) |
| 흰색 White | 미연결 | 🚨 절연·개방 (독립사용 시 4번단자 open, 데이터시트 Note1) |

- 🚨 6선 컨트롤러는 아날로그=**회색**이지만, 4선 독립헤드는 아날로그=**검정**. 신호선=검정.
- 독립 헤드 = **1~5V 전압출력 고정**(4~20mA 선택은 컨트롤러 기능, 여기선 없음) → A0/A1 **직결**, 센스저항 불필요. 우노 ADC 입력임피던스(~100MΩ) ≫ 데이터시트 요구(50kΩ↑) OK.
- 헤드 2개 → 각 검정선 A0·A1. 전원(갈/파) 공유. bar 환산은 호스트(브리지/GCS).

## 5. 공통 접지 (필수)
우노 GND · 릴레이 코일 5V GND · SBD-20 GND(24V−) · 압력센서 GND 를 **한 점**으로.

## 6. 부팅 안전 상태
릴레이 전부 CLOSED, 스텝 EN 해제(idle). `client_dock.ino` setup()에서 보장.
